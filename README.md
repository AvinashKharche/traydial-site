# TrayDial public pages

Public site for Praxlo Labs, contact support@praxlo.com.

Published from the separate public repository `AvinashKharche/traydial-site` at https://avinashkharche.github.io/traydial-site/. Only public HTML and CSS are copied into that repository; application source and credentials stay private.

Use `privacy.html`, `support.html`, and `terms.html` for the app configuration. Play account-deletion URL: `support.html#delete`. Update this folder and the site repository together for future policy changes.

Cloud and billing activation still require provider configuration and on-device testing. Publication does not establish store approval.
