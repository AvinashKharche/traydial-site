# TrayDial public pages

Public site for Praxlo Labs, contact support@praxlo.com, hosted at https://traydial.pages.dev on Cloudflare Pages.

The `traydial` Pages project uses Direct Upload. Upload only `index.html`, `privacy.html`, `support.html`, `terms.html`, and `style.css` (a ZIP with these files at its root works). Application code and credentials are never part of the public upload.

Use `/privacy.html`, `/support.html`, and `/terms.html` for app configuration. Play account-deletion URL: `https://traydial.pages.dev/support.html#delete`.

The temporary GitHub Pages deployment was retired after switching to the neutral Cloudflare address. Cloud and billing activation still require integration and on-device testing. Publication does not establish store approval.
